## 1. 决策链（为什么这么改）

| 阶段 | 触发 | 决策 | 效果 |
| --- | --- | --- | --- |
| 合规 | 客户/厂商名可被溯源 | 白标清洗：文本 grep + 截图重制 + OCR 兜底 | 品牌叙事成立 |
| 专业感 | 中小老板不会验代码 | Apple 浅色风 + 真实界面截图 + 20+ 落地版图 | 「像正经公司」 |
| 定位 | 软件不好卖、手机好卖 | 客群=能做 demo 做不了运营的中小老板；代理=增长引擎 | 漏斗成型 |
| 入口 | 培训/教练是最强武器 | 玄龙工作坊（对外无名，课件留存） | 获客载体就位 |

一句话商业逻辑：工作坊筛人 → 手机成交 → 底座留客 → 代理放大。

## 2. 做对了的（可复制做法）

- **真实资产优先于造图**：产品截图全部来自真实运行界面，比 mockup 说服力高一档；图片统一 1680w Web 压缩（q84）。
- **对比站打样**：白标话术框架参考同行站（playwright 抓 SPA，只学结构不抄品牌），性价比最高的市场调研。
- **验证流水线脚本化**：双端渲染断言脚本一次编写全程复用，每次改动只改端口。
- **一键换链接**：下载区 manifest JSON 化，发新版只改版本号/文件名/体积三处；干跑假链接验证替换逻辑后再动真站。

## 3. 踩过的坑

| 坑 | 现象 | 对策（已立规） |
| --- | --- | --- |
| HTML 手拼漏闭合 | 卡片段少 `<ul>`，靠 html.parser 栈检查兜出 | verify-before-live 辅助纪律 |
| 测试脚本模式过时 | badlink 误报新链接（只认旧路径） | 链接独立 curl 复验，不信脚本内模式 |
| 内网链接泄漏 | 资产下载 API 返回内网地址 | 官网一律重写为对外域名 |
| push 443 超时 | 连续失败两次 | 退避重试；第三次成功 |
