# 工作坊落地页信息架构：漏斗四段式定稿

- 日期：2026-11-05
- 状态：已定稿（owner 认可）
- 范围：chai.aibay.asia/workshop/（01 期首场页）；02 期页同骨架适用

## 背景

owner 指出 workshop 首页「资料呈现的前后逻辑不顺」。复盘发现根因：**页面把「操作层」放在了「认知层」前面**——新访客还没被说服为什么要来，就先看到领钥匙、贴提示词这些准备动作。旧顺序为：hero → 实录 → 开工前三件事 → 提示词 → 课程资料 → 痛点 → 三件收获 → 3小时怎么上 → 课前视频 → 九步工作流 → 讲师 → 报名 → 索引 → 反馈。痛点/收获/课程结构（说服层）被压到中部，「开工前三件事」「提示词」是已报名者才用的却放在最前，纯工具性的「课前视频」「快捷入口」混在说服内容和讲师之间。

## 决策：漏斗四段式

按访客状态排段，先说服 → 再成交 → 后备课 → 课后回看：

1. **说服**：hero → 你是不是也这样（痛点）→ 三件真东西（收获）→ 3 小时怎么上（结构）→ 九步工作流+RSI+护栏（硬核亮点）
2. **成交**：主讲拆书家 → 报名信息
3. **备课**（分隔线「以下为课前准备与课后资料」之后）：首场实录 → 开工前三件事 → WorkBuddy 提示词 → 课前视频 → 现场快捷入口
4. **课后**：现场全套课程资料 → 本页材料索引 → 课后反馈

## 规则（落规）

- 工作坊落地页一律按漏斗四段排块；纯工具性内容（快捷入口、提示词、准备清单）不得插入说服段与成交段之间。
- 已报名者才用的内容（备课段）与招新内容（说服+成交段）之间须有视觉分隔线。
- 重排只移动 HTML 块，不改文案不改样式——文案变更走 owner 逐字定稿流程（见 2026-11-04-owner-final-wording-literal）。

## 教训

- 「资料全」不等于「顺序对」：内容齐了之后必须再过一遍信息架构，问自己"第一次来的人此刻需要被说服还是被指导"。
- 两类受众（未报名/已报名）混排是落地页大忌；先分段再排块。
