# D18：第二期升级——一库一站一号内容飞轮 + 分组组长五职责 + 共享材料 10/11（2026-11-01）

## 背景与主张
第二期（2026-11-08）不是重讲一遍建站，而是**承接第一期**：学员已有 ima 知识库（库）与公众号（号），本期补上网站（站），把三者接成飞轮。
- 主张：**库是源头、站是门面、号是分发、复盘回库**；记忆句「网站不是终点，是飞轮的第二个出口」「素材只写一次，处处都在」。
- 硬口径：**只承诺公众号草稿箱，绝不承诺当天群发**（审核/授权不可控）；公众号 AppID 可现场记录，**AppSecret 与 IP 白名单不现场配**（账号安全红线）。
- 新学员兜底：第 0 节 20 分钟现场补齐，写「没配好不影响上课」，不写「不完成不能上课」。

## 矩阵执行与坑
- 满编四块：A 02 主页（wechat）/ B 材料 01–05（openclaw）/ C 材料 06–09（hermes）/ D 共享 10–11（xinma），bundle2 分发、out 回传、本地合入并逐份审校。
- 坑 1：`.sheet{min-height}` 写在 `<style>` 里会**穿透 @media print**，导致整页强行多一页——打印必须在 print 媒体里把 min-height 归零，或只在 `@media screen` 中设置。
- 坑 2：`handout.css` 给 `table` 显式 `font-size:11.8px`，只缩 `body` 字号对表格无效——压单页必须同时缩 table 字号。
- 坑 3：块产出统一引用 `../wk2handouts/` 与硬编码 wk2 日期，落仓前需 sed 成同目录相对路径、共享材料改「六场通用」页眉。
